## 🚀 UniNote v0.4.8 — Gomma avanzata a 120 Hz, dock dinamico, zoom 10x e cloud in-app

Questa release estende notevolmente le capacità di disegno e organizzazione di UniNote: introduce un indicatore live del raggio di cancellazione con popover dedicato, la gestione dinamica dei pennini nel dock, uno zoom esteso fino a 10x con calibro ultra-fine e il collegamento diretto in-app con Nextcloud e Google Drive.
L'intero aggiornamento è stato convalidato con la suite di test del progetto (100% test superati, 0 avvisi).

---

### 🌟 Punti Chiave dell'Aggiornamento

#### 🩹 1. Gomma avanzata con indicatore circolare live a 120 Hz e popover modalità
Cancellare con precisione diventa immediato grazie al doppio anello visivo tracciato in tempo reale sul canvas al passaggio dello stilo, che mostra l'esatta area di impatto. Il nuovo popover agganciato alla barra degli strumenti permette di scegliere con un tocco tra cancellazione del tratto intero e sezionamento analitico Bézier, con slider del raggio (da 4 a 64 px) e preset rapidi (Fine, Medio, Grande).

#### 🖋️ 2. Dock penne dinamico con menu contestuale ed eliminazione sicura
È ora possibile personalizzare liberamente il numero e la configurazione dei propri pennini: facendo clic destro o tenendo premuto lo stilo su uno slot compare un menu contestuale per cambiare colore o rimuovere la penna indesiderata. Una salvaguardia impedisce di rimuovere l'ultimo pennino attivo per garantire che l'editor sia sempre pronto alla scrittura.

#### 🔍 3. Zoom esteso a 10.0x e calibro ultra-fine da 0.25 pt
Per scrivere formule matematiche dense, schemi geometrici o annotare slide PDF universitarie nei dettagli più minuti, il canvas supporta ora un ingrandimento fino a 10x senza perdita di nitidezza vettoriale. La griglia procedurale si adatta automaticamente generando una micro-griglia fine, mentre il nuovo calibro penna da 0.25 pt (con preset rapido "Micro" a 0.3 pt) consente tratti definiti anche negli spazi più ristretti.

#### ☁️ 4. Collegamento diretto in-app per Nextcloud e Google Drive
UniNote può ora connettersi direttamente al proprio cloud universitario o personale: una finestra modale guida il collegamento a Nextcloud (tramite WebDAV sicuro) e a Google Drive. I quaderni cloud vengono memorizzati in una directory locale isolata protetta, senza interferire con altre cartelle del sistema, e compaiono con un'icona dedicata nella barra laterale della Dashboard per sfogliare, creare e sincronizzare note in piena trasparenza.

### 📦 Come Installare o Aggiornare

I pacchetti precompilati sono allegati direttamente a questa release:

#### 🐧 Flatpak (Consigliato per tutte le distribuzioni Linux)

```bash
flatpak install --user ./org.uninote.UniNote.flatpak
flatpak run org.uninote.UniNote
```

#### 📁 Pacchetto Tarball Portatile (Linux x86_64)

```bash
tar -xzf uninote-v0.4.8-linux-x86_64.tar.gz
cd uninote-v0.4.8-linux-x86_64
./install.sh
```

Verifica dell'integrità del download:

```bash
sha256sum -c uninote-v0.4.8-linux-x86_64.tar.gz.sha256
```

#### 🏗️ Arch Linux / CachyOS (Pacchetto precompilato)

```bash
sudo pacman -U uninote-0.4.8-1-x86_64.pkg.tar.zst
```

In alternativa, build dai sorgenti con il `PKGBUILD` incluso in `packaging/aur/`.
