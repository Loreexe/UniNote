## 🚀 UniNote v0.4.9 — Correzione robustezza gomma a segmenti e stabilità vettoriale

Questa release di manutenzione risolve un'anomalia critica di cancellazione nello strumento Gomma a Segmenti che poteva provocare la chiusura anomala dell'applicazione (crash con SIGABRT) durante passaggi ripetuti dello stilo su tratti complessi.
L'aggiornamento introduce una completa risincronizzazione della cache geometrica Bézier, controlli rigorosi sui confini degli array e guardie di finitezza numerica, convalidati al 100% dalla suite di test del workspace.

---

### 🌟 Punti Chiave dell'Aggiornamento

#### 🛡️ 1. Sincronizzazione rigorosa della cache Bézier cubica
In precedenza, quando un tratto vettoriale veniva parzialmente cancellato e ricostruito con campioni geometrici deduplicati, la cache interna dei segmenti Bézier poteva mantenere un numero di segmenti superiore rispetto all'array dei punti sopravvissuti. La nuova versione verifica sistematicamente l'allineamento della cache prima di ogni operazione di taglio, ricalcolando dinamicamente la spline di Catmull-Rom quando necessario e garantendo una perfetta coerenza strutturale.

#### 🔒 2. Bounds Clamping difensivo e prevenzione panic in FFI/GTK
L'algoritmo di sezionamento protegge ora ogni accesso agli indici dei punti e dei segmenti tramite clamping di sicurezza e recupero controllato (`points.get(k)`). Questo previene alla radice qualsiasi errore di indice fuori limite (`index out of bounds`) e scongiura tentativi di unwinding del runtime Rust attraverso i confini FFI C delle callback di movimento dello stilo GTK4, preservando la continuità della sessione di lavoro.

#### 📐 3. Guardie di finitezza numerica e ripristino automatico
Introdotta la verifica di finitezza (`is_finite()`) su coordinate e parametri dei segmenti Bézier, bloccando preventivamente eventuali valori degeneri (`NaN` o infinito). La procedura `ensure_cache()` è stata inoltre potenziata per riparare automaticamente qualsiasi cache disallineata o degradata, mantenendo la modalità `Baseline` rigorosamente priva di cache superflue per salvaguardare lo storage.

### 📦 Come Installare o Aggiornare

I pacchetti precompilati sono allegati direttamente a questa release:

#### 🐧 Flatpak (Consigliato per tutte le distribuzioni Linux)

```bash
flatpak install --user ./org.uninote.UniNote.flatpak
flatpak run org.uninote.UniNote
```

#### 📁 Pacchetto Tarball Portatile (Linux x86_64)

```bash
tar -xzf uninote-v0.4.9-linux-x86_64.tar.gz
cd uninote-v0.4.9-linux-x86_64
./install.sh
```

Verifica dell'integrità del download:

```bash
sha256sum -c uninote-v0.4.9-linux-x86_64.tar.gz.sha256
```

#### 🏗️ Arch Linux / CachyOS (Pacchetto precompilato)

```bash
sudo pacman -U uninote-0.4.9-1-x86_64.pkg.tar.zst
```

In alternativa, build dai sorgenti con il `PKGBUILD` incluso in `packaging/aur/`.
