## 🚀 UniNote v0.4.7 — Editing avanzato, impostazioni rinnovate e nuova identità visiva

Questa release porta UniNote un passo più vicino a un editor di appunti completo: si possono trasformare e ritagliare i tratti già disegnati, con annullamento e ripristino affidabili, mentre l'interfaccia delle impostazioni è stata ridisegnata e arricchita con un pannello GitHub per verificare gli aggiornamenti. L'intero lavoro è stato validato con la suite di test del progetto (982 test, 0 warning).

---

### 🌟 Punti Chiave dell'Aggiornamento

#### 🎨 1. Impostazioni ridisegnate in stile Material 3 con scheda GitHub
La finestra delle preferenze è stata riorganizzata con i componenti Adwaita più recenti: gruppi di impostazioni più leggibili, descrizioni chiare e ricerca immediata delle voci. La nuova scheda **GitHub** raccoglie i collegamenti al repository, alle segnalazioni e alle note di rilascio, e permette di verificare in modo sicuro l'ultima versione pubblicata confrontandola con quella installata, senza inviare dati personali.

#### 📋 2. Selezione con clipboard, dashboard delle cartelle e navigazione laterale
È ora possibile selezionare porzioni di pagina e copiarle o incollarle come appunti, mantenendo la formattazione vettoriale. La schermata iniziale mostra una dashboard delle cartelle con anteprime e statistiche, mentre la barra laterale consente di spostarsi rapidamente tra quaderni, sezioni e pagine senza perdere il contesto.

#### 🧩 3. Trasformazioni affini dei tratti con cronologia completamente reversibile
I tratti selezionati possono essere spostati, ridimensionati e ruotati tramite trasformazioni affini che preservano la qualità vettoriale della linea. Ogni operazione passa per un comando dedicato (`DocCommand`), quindi ogni modifica è annullabile e ripristinabile in modo atomico, con l'indice spaziale R-Tree sempre coerente.

#### 🩹 4. Gomma per segmento e maniglie di ridimensionamento interattive
La gomma non cancella più l'intero tratto: un algoritmo di taglio delle curve di Bézier (de Casteljau) rimuove solo il segmento toccato, lasciando intatti i tratti adiacenti. La selezione mostra 8 maniglie perimetrali con trascinamento per il ridimensionamento e perno sul lato opposto; le maniglie si riducono automaticamente sulle selezioni molto piccole per non coprire il contenuto.

#### 🖋️ 5. Nuova identità visiva: penna a sfera e icona vettoriale
Il marchio UniNote è stato ridisegnato con una "U" calligrafica tracciata a penna, accompagnata da una nuova icona applicativa SVG che rappresenta una penna a sfera inclinata di 25°. Le icone raster hicolor sono state rigenerate da 16 a 512 pixel per una resa nitida su ogni desktop.

### 📦 Come Installare o Aggiornare

I pacchetti precompilati sono allegati direttamente a questa release:

#### 🐧 Flatpak (Consigliato per tutte le distribuzioni Linux)

```bash
flatpak install --user ./org.uninote.UniNote.flatpak
flatpak run org.uninote.UniNote
```

#### 📁 Pacchetto Tarball Portatile (Linux x86_64)

```bash
tar -xzf uninote-v0.4.7-linux-x86_64.tar.gz
cd uninote-v0.4.7-linux-x86_64
./install.sh
```

Verifica dell'integrità del download:

```bash
sha256sum -c uninote-v0.4.7-linux-x86_64.tar.gz.sha256
```

#### 🏗️ Arch Linux / CachyOS (Pacchetto precompilato)

```bash
sudo pacman -U uninote-0.4.7-1-x86_64.pkg.tar.zst
```

In alternativa, build dai sorgenti con il `PKGBUILD` incluso in `packaging/aur/`.

- I file `.uninote` creati con le release precedenti restano apribili senza migrazioni manuali.
