## 🚀 UniNote v0.4.14 — Selezione, Manipolazione Interattiva, Miniature Dashboard ed Esportazione PDF per Immagini (Fase 4D - M3 & M4)

Questa release porta a compimento le Milestone M3 ed M4 della Sotto-Fase 4D:
1. **Milestone M3**: selezione interattiva avanzata di immagini raster (`ItemKind::Image`) con click/tap diretto in ordine di $z$-index decrescente, selezione ad area (rettangolare e lazo), unificazione bounding box misti (tratti + immagini), manipolazione a 120 Hz con 8 maniglie perimetrali attorno al perno opposto, traslazione drag fluida, cancellazione atomica e pieno supporto Undo/Redo.
2. **Milestone M4**: rendering delle miniature di anteprima dei documenti (`render_document_thumbnail_with_store`) nella dashboard $240 \times 340$ px sia per Quaderno A4 che per Lavagna Infinita con caricamento trasparente da SQLite WAL, ed esportazione vettoriale PDF ad alta risoluzione (`export_to_pdf_with_store`) con rasterizzazione cairo nativa degli asset immagine sia in tema chiaro che scuro.

---

### 🌟 Punti Chiave dell'Aggiornamento

#### 🔲 1. Selezione Interattiva ed Hit-Testing Z-Index (Milestone M3)
- **Hit testing diretto**: toccando o cliccando su qualsiasi immagine con lo strumento Selezione (`ActiveTool::Select`), l'interazione valuta gli elementi in ordine di $z$-index decrescente (dall'elemento più recente a quello più vecchio), garantendo la selezione immediata dell'immagine posta in primo piano.
- **Supporto Lazo e Rettangolo**: l'algoritmo di selezione rettangolare (`is_image_selected_by_rect`) e a lazo poligonale (`is_image_selected_by_lasso`) integra il controllo perimetrale a 4 vertici dell'immagine e la verifica del centroide, consentendo selezioni flessibili singole o composte.
- **Bounding Box Misti**: calcolo unificato dei limiti geometrici (`combine_selection_bboxes`) per gruppi eterogenei composti da tratti vettoriali e immagini.

#### 📐 2. Manipolazione con 8 Maniglie e Traslazione Fluida 120 Hz
- **8 Maniglie di Ridimensionamento**: maniglie angolari e mediane (Top-Left, Top, Top-Right, Right, Bottom-Right, Bottom, Bottom-Left, Left) con ridimensionamento proporzionale ancorato rigidamente al perno geometrico opposto, evitando deformazioni involontarie.
- **Traslazione Drag & Drop**: trascinamento reattivo in tempo reale con registrazione atomica delle trasformazioni (`DocCommand::TransformItems` e `DocCommand::MoveItems`) nella cronologia di annullamento.
- **Cancellazione Atomica**: pressione di `Canc`/`Backspace` per eliminare immagini e tratti selezionati con ripristino istantaneo via `Ctrl+Z` / `Ctrl+Y`.

#### 🖼️ 3. Miniature Dashboard con Supporto Immagini (Milestone M4)
- **Rendering Anteprima Realistico**: la dashboard visualizza anteprime fedeli ($240 \times 340$ px) dei documenti contenenti immagini, caricando gli asset direttamente dalla cache in memoria o da SQLite WAL.
- **Risoluzione per Quaderno e Lavagna**: supporto per viewport A4 ancorata e viewport adattiva per lavagna infinita.

#### 📄 4. Esportazione PDF Vettoriale ad Alta Risoluzione con Immagini (Milestone M4)
- **Superficie Cairo PDF**: le immagini incorporate nel documento vengono rasterizzate con fedeltà sub-pixel sulla superficie PDF multipagina (`export_to_pdf_with_store`), preservando il canale alfa e il corretto $z$-ordering rispetto ai tratti a mano libera e agli evidenziatori.
- **Supporto Dual Light / Dark**: perfetto contrasto e corretta resa cromatica sia nella modalità standard che scura.

### 📦 Come Installare o Aggiornare

#### 🏗️ Arch Linux / CachyOS (Pacchetto precompilato)

```bash
sudo pacman -U uninote-0.4.14-1-x86_64.pkg.tar.zst
```

Oppure installazione locale via AUR / makepkg:

```bash
cd packaging/aur/uninote && makepkg -si
```

#### 🐧 Flatpak (Consigliato per tutte le distribuzioni Linux)

```bash
flatpak install --user ./org.uninote.UniNote.flatpak
flatpak run org.uninote.UniNote
```

#### 📁 Pacchetto Tarball Portatile (Linux x86_64)

```bash
tar -xzf uninote-v0.4.14-linux-x86_64.tar.gz
cd uninote-v0.4.14-linux-x86_64
./install.sh
```
